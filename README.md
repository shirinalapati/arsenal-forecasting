# Arsenal Forecasting (deployed site)

Static build of the research app and presentation for **"Can we predict how MLB pitchers will change their
arsenals before next season?"**, a preregistered forecasting study on 2021–2026 Statcast season aggregates
with pitcher-specific 2027 forecasts.

- Research app: https://shirinalapati.github.io/arsenal-forecasting/
- Presentation mode: https://shirinalapati.github.io/arsenal-forecasting/#/presentation

This repository holds only the built site (HTML, JavaScript, CSS and the derived JSON the app displays).
2027 forecasts are prospective and conditional on each pitcher qualifying in 2027.
