# Arsenal Forecasting (deployed site)

Static build of the research app and presentation for "Can we predict how MLB pitchers will change their arsenals
before next season?": two independently built forecasting approaches on 2021–2026 Statcast season aggregates, each
locked and scored once on the 2025→2026 test year, and a combined 2027 forecast system assembled after both results
were seen.

- Research app: https://shirinalapati.github.io/arsenal-forecasting/
- Presentation mode: https://shirinalapati.github.io/arsenal-forecasting/#/presentation

This repository holds only the built site (HTML, JavaScript, CSS and the derived JSON the app displays). 2027 forecasts
are prospective, not validated outcomes, and conditional on each pitcher qualifying in 2027.
